# MagnitApp — веб-застосунок (PWA), повна заміна Telegram-бота

Той самий функціонал, що й Telegram-бот OblikMagnit, але без залежності
від Telegram: власний сервер (backend) і встановлюваний веб-застосунок
(PWA), який НЕ потребує Google Play чи будь-якої публікації.

## Встановлення (на комп'ютері/сервері, де працюватиме backend)

```bash
cd magnitapp/backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
# На Debian/Ubuntu/Kali для pyzbar додатково потрібна системна бібліотека:
sudo apt install libzbar0
```

## Запуск

```bash
export JWT_SECRET="довгий-випадковий-рядок-тут"       # секрет для токенів входу
export HEAD_ADMIN_USERNAME="admin"                     # логін головного адміна (створюється 1 раз)
export HEAD_ADMIN_PASSWORD="надійний-пароль-тут"
python3 app.py
```

Бот стартує на порту 5000 і одразу роздає і backend (`/api/...`), і сам
застосунок (все на одному порту, окремий сервер для фронтенду не потрібен).

**Головний адмін створюється лише один раз** — при першому запуску, якщо
в базі ще немає жодного користувача. Наступного разу ці змінні можна не
вказувати (пароль уже збережено в базі).

## Встановлення застосунку на телефон (без Google Play)

1. Відкрийте в браузері телефону (Chrome на Android, Safari на iPhone)
   адресу вашого сервера, наприклад `http://адреса-сервера:5000`
2. Android (Chrome): з'явиться підказка «Додати на головний екран», або
   через меню (три крапки) → «Встановити застосунок»
3. iPhone (Safari): кнопка «Поділитися» → «На екран Домівки»
4. Готово — застосунок з'явиться як звичайна іконка, відкриватиметься на
   весь екран, без адресного рядка браузера

## Важливо: доступ по мережі

Щоб телефон міг підключитись до сервера, потрібна одна з умов:
- Сервер і телефон в одній Wi-Fi мережі → використовуйте локальну IP-адресу
  комп'ютера (наприклад `http://192.168.1.50:5000`)
- Або сервер розміщено на хмарному VPS з публічною адресою (рекомендовано
  для реальної щоденної роботи - тоді доступ буде з будь-якої мережі)

**Камера в браузері вимагає HTTPS** (крім `localhost`) — якщо телефон і
сервер в одній локальній мережі по звичайному `http://`, фотографування
може не працювати через обмеження браузера. Для повноцінної роботи камери
рекомендується налаштувати HTTPS (наприклад, безкоштовний сертифікат
через Let's Encrypt, якщо сервер має публічну адресу і домен).

## Перший вхід

1. Увійдіть як головний адмін (логін/пароль, які вказали в змінних середовища)
2. Додайте продавців: 👥 Продавці → вкажіть логін, пароль і торгову точку
3. Дайте продавцям їхні логін/пароль для входу з телефону

## Що вже реалізовано

- Продаж/додавання товару через фото (штрихкод + порівняння за схожістю)
- Прихід товару, зміна кількості
- **Запити на зміну залишку**: продавець змінює кількість → адмін отримує
  push-сповіщення і підтверджує/відхиляє (як у Telegram-версії)
- **Переоблік точки**: масова звірка кількості по всіх товарах
- **Push-сповіщення адміну** (без Telegram!): запити на зміну залишку,
  пропуск номера квитанції, завершення переобліку
- **Excel-звіти**: продажі (по точці й по всіх точках), ремонти
- Ремонти: прийняття квитанції з перевіркою на пропуск номера, видача
  клієнту зі списку, звіт по точці, список ще не виданих
- Адмін: продавці, головний адмін → адміни, зміна ціни за штрихкодом,
  перейменування/очищення точки, звіти продажів (по точці за період,
  всі точки сьогодні)

## Push-сповіщення: додатковий крок налаштування

На відміну від решти функціоналу, push-сповіщення потребують **HTTPS**
для роботи (браузери не дозволяють Web Push на звичайному `http://`,
крім `localhost`). Якщо сервер має публічну адресу з доменом -
налаштуйте безкоштовний сертифікат (Let's Encrypt). Без HTTPS усе інше
(продаж, прихід, звіти) працюватиме, а сповіщення - ні.

Бібліотека `pywebpush` (для реальної відправки) не встановлена в
середовищі розробки цього застосунку - логіка написана і перевірена
структурно, але **справжню доставку сповіщення варто перевірити на
вашому реальному сервері** з реальним браузером після встановлення:

```bash
pip install pywebpush
```

## Обмеження цієї версії (чесно, наперед)

- Push-дії прямо у сповіщенні (наприклад, кнопки "Підтвердити"/"Відхилити"
  прямо в самому сповіщенні) не реалізовані - потрібно відкрити застосунок
  і перейти в «🔔 Запити»
- База даних SQLite - для 4 точок цього більш ніж достатньо, але це не
  розрахована на дуже великі навантаження база

Якщо щось із цього критично потрібне - скажіть, і
допрацюємо саме це в першу чергу.
